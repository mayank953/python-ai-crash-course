# Python + AI Crash Course

Everything you need to follow the **13-hour Python + AI Crash Course** on YouTube: every notebook,
every whiteboard note, practice questions, and a visual guide to 21 core AI concepts.

No prior programming experience needed. By the end you will be able to write Python programs with
variables, strings, operators, conditionals, loops, data structures and functions, and you will
understand the vocabulary behind modern AI (LLMs, tokens, RAG, MCP, agents and more).



## How to use this repo

1. **Watch** a chapter of the video (timestamps below).
2. **Skim** the whiteboard notes PDF from the lesson folder.
3. **Read** `theory.ipynb`, then **run** `code.ipynb` yourself. Change values, break things, fix them.
4. **Practise** with the `exercises` notebooks where a lesson has them.
5. Move to the next lesson. Lessons are numbered in video order.

## Getting started

You need Python 3.9+ and Jupyter. Pick one route.

**Option A: plain Python + venv (recommended)**

```bash
git clone <this-repo-url>
cd <repo-folder>
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
jupyter lab
```

**Option B: Anaconda** (shown in the video at `20:31`): install Anaconda, run `jupyter notebook`
from the repo folder, and open any `.ipynb` file.

**Option C: no install:** upload a notebook to [Google Colab](https://colab.research.google.com/)
(File, then Upload notebook).

The notebooks only use the Python standard library, so no extra packages are needed.

## FAQ

**A notebook won't open on GitHub.** Download the repo (Code, then Download ZIP) and open it with Jupyter.

**Do I need to install anything for the AI part?** No. It is concepts and diagrams only.

**What's the difference between `theory` and `code` notebooks?** `theory` explains the idea with notes and
small examples; `code` is the live-class code with outputs, to run and modify.

**I found a mistake.** Please open an issue or pull request.
