**Try it yourself**

1. Use `in` and `not in` on a string, a list and a dictionary's keys.
2. Compute `10 & 6`, `10 | 6` and `10 ^ 6`, and confirm each with `bin()`.
3. Use a left shift to compute `1 << 5` and explain it as multiplication.
